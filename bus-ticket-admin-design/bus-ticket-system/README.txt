Bus Ticket System - Admin Dashboard (HTML/CSS/JS)

চালানোর নিয়ম:
1. এই ফোল্ডার C:\xampp\htdocs\bus-ticket-system\ এ কপি করুন।
2. ব্রাউজারে খুলুন: http://localhost/bus-ticket-system/admin/dashboard.html
   (অথবা dashboard.html ডাবল-ক্লিক করুন; ইন্টারনেট লাগবে কারণ Bootstrap/Chart.js CDN থেকে আসে)

পরের ধাপ (PHP):
- dashboard.html -> dashboard.php
- navbar/sidebar আলাদা করে includes/ এ নিন
- নমুনা সংখ্যা ও টেবিল ডাটাবেস থেকে আনুন
